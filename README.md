# MMPA-Decay-Solver

**Status:** Planning / Early development 📝

Mini-Max Polynomial Approximation (MMPA) solver for matrix exponentials in nuclear decay chains. Will be verified against the Bateman analytical solution for U-238 → Th-234 → Pa-234m → U-234, and tested on a gadolinium-157 absorber case for multi-time-point evaluation.

## Project Scope

- Decay chain verification (4 isotopes)
- Absorber case (gadolinium-157)
- Performance benchmarking vs SciPy Radau
- Speed-accuracy trade-off analysis
